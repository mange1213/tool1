# Tool App

A single workshop equipment app combining the File 1 and File 2 features, with File 1's red-and-black layout.

## Included features
- Equipment register with categories, search, status, quantity, weight and CSV import/export template
- Worker records and archives
- Multi-item check-out and check-in with due dates, inspection checks and notes
- Damaged and missing equipment tracking
- Overdue and due-soon dashboard reminders
- Equipment and worker history, reports and print views
- Complete backup, restore, share and automatic local backup
- Browser notifications and installable app support

Photos are not included. The app stores data in this browser/device; use Backup / Restore to move data or keep a copy.

## Publish
Upload the contents of this folder to the root of a GitHub Pages repository. Keep the files together, including `index.html`, `manifest.webmanifest`, `sw.js`, and the image assets.
